About the table

Built for the table, not the feed.

These are games with memory: the cards you have seen, the suit you are void in and the trick you cannot afford to lose. The interface should stay out of the way of that thinking.

Every table here is designed to be read at a glance - clear targets, honest feedback and cards that look like cards. Start with 7–8; the rest will arrive when they are ready to be played properly.

Rules firstNo rule changes for spectacle. The game is the point.
One screenNo account, no lobby, no loading between ideas.
Made to be readLarge targets, labelled groups and keyboard play.
Quiet by defaultMotion that explains the table, not motion for its own sake.
